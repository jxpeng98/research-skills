# Qiongli 2.0.0-alpha.6 — CLI Alpha

Qiongli 2 now ships as a standalone Rust CLI with Lite and Full MCP. This release
provides **macOS Apple Silicon (macOS 11+)** download packages. No Qiongli App or
Community Alpha installer is required. Your chosen Host owns models and credentials.

## Download and run

Download `qiongli-2.0.0-alpha.6-aarch64-apple-darwin.tar.gz`,
`release-manifest.json`, and `SHA256SUMS` from this release. In that directory:

```sh
shasum -a 256 --check --ignore-missing SHA256SUMS
mkdir qiongli-alpha6
tar -xzf qiongli-2.0.0-alpha.6-aarch64-apple-darwin.tar.gz -C qiongli-alpha6
./qiongli-alpha6/qiongli --version
./qiongli-alpha6/qiongli --help
./qiongli-alpha6/qiongli doctor
```

The standalone executable needs no Node, Python or Cargo. This Alpha is not
Apple notarized; macOS download security may require explicit user approval.

For MCP, configure your Host with the executable's absolute path and arguments
`mcp serve --profile full --transport stdio` (32 tools), or use `lite` (14 tools).
CLI project/Capture/Graph inspection, embedded research content, retrieval and
Zotero/recovery commands retain their existing interfaces and prerequisites.
Research writes continue to require the existing preview, approval and revision
checks. Models and provider credentials are not bundled or transferred.

## Optional npm or Python installation from release files

Download and verify the corresponding attachment, then choose one:

```sh
npm install --global ./qiongli-2.0.0-alpha.6.tgz
```

```sh
python3 -m venv qiongli-alpha6-venv
qiongli-alpha6-venv/bin/python -m pip install ./qiongli-2.0.0a6-py3-none-macosx_11_0_arm64.whl
qiongli-alpha6-venv/bin/qiongli --version
```

Both packages contain the same executable and expose `qiongli` and `ql`.
Node 18+ or Python 3.9+ is needed only for the selected wrapper. These are GitHub
download assets; **this release does not upload alpha.6 to npm, PyPI or crates.io**.
For a Cargo source build, check out this exact tag, enter
`packages/qiongli-native`, then run
`cargo install --path apps/qiongli --bin qiongli --no-default-features --locked`.
The repository pins Rust 1.97.0. This source command is not a crates.io install.

## Alpha limitations and upgrade

- Managed Plugin/Skill activation, automatic migration and signed self-update
  still require their existing managed-product authority. This direct download
  does not enable them. No full 1.x replacement or completed end-to-end research
  workflow qualification is claimed.
- Windows installation remains partially complete/paused. No Windows or Linux
  executable is advertised by this macOS release.
- Install a new version into a separate directory and select it in PATH or the
  Host configuration. Keep the previous executable for rollback. Preserve research
  data/backups; selecting an older executable does not undo data migrations.
- Uninstall by removing your extracted directory/venv or using `npm uninstall -g
  qiongli`, then remove only the PATH/Host entry you added. Research data is separate.

`release-manifest.json` binds the exact source commit, toolchain, tested target
and asset hashes. The local gate checks CLI-only format/Clippy/tests, extracted
CLI/MCP execution, and isolated npm/wheel installation. GitHub assets and tags are
immutable; any fix ships as a new version.
