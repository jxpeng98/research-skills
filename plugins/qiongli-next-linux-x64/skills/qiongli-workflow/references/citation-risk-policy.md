# Citation Risk Policy

Use this policy before final manuscript, proofread, submission, rebuttal, or presentation outputs.

## Risk Categories

- `missing_source`: claim has no source pointer.
- `source_not_in_bibliography`: ledger source ID is absent from `bibliography.bib`.
- `weak_support`: source is related but does not directly support the claim.
- `wrong_construct`: citation supports a different construct, population, or mechanism.
- `outdated_source`: claim depends on current facts but uses stale evidence.
- `review_as_primary`: review cited as primary empirical evidence.
- `citation_pile`: many citations are listed without synthesis.
- `invented_metadata`: bibliographic fields cannot be verified from project artifacts.

## Required Output

Write `RESEARCH/[topic]/proofread/citation-risk-report.md` or attach the same sections to the relevant final review artifact.

## Rules

- Cite primary empirical evidence for empirical claims.
- Cite reviews or meta-analyses for field state, not as substitutes for primary results.
- Cite theory sources for construct definitions and mechanism claims.
- Cite method sources for estimators, diagnostics, and reporting standards.
- Cite dataset and code sources when data or software provenance matters.
- Convert unverifiable source claims into gap notes rather than polishing them as facts.
