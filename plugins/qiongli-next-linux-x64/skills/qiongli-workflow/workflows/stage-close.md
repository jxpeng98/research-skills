# Stage Consolidation

Use when the user wants to summarize a completed stage, preserve accumulated
work, prepare the next stage, or review old project files for manual cleanup.
This does not itself pass a research gate or complete unfinished tasks.

Read `skills/Z_cross_cutting/academic-context-maintainer.md` and
`references/stage-consolidation.md`. Use `templates/stage-summary.md` for the
versioned document. Reuse the selected project, stage and supplied scope; ask
only when the destination or permitted source material is unclear.

Keep the detailed research content, source anchors and changes since the prior
summary. Humanize the consolidated narrative through the final language pass in
`references/stage-consolidation.md`, then show exact proposed document/index writes before applying through the
existing authorized write path. Preserve source files and earlier summaries.
For an unsaved overview, return it in chat without creating a project.

Return the document link, covered/deferred material, changes and next-stage
priorities. Include a per-file retention review only when cleanup is requested.
All files start retained. The user chooses individual files and performs any
deletion personally. Do not delete, trash, move, truncate or overwrite source
files, and do not generate a deletion script, command or automatic cleanup job.
User selection does not authorize the assistant to execute removal.
