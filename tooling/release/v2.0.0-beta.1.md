# Qiongli v2.0.0-beta.1 — standalone downloads and Cargo

> **Cargo availability:** the source packages passed all three platform checks,
> but the crates.io upload is still pending. Use the standalone downloads, npm
> or PyPI for now.

This first 2.x beta packages the CLI, research Skills and Lite/Full MCP for
macOS Apple Silicon, Windows x64 and Linux x64 (glibc 2.35+). Codex is the primary
Host; other Hosts use the shared contracts and keep their configured models.

## What changed

- Download, extract and run the complete CLI without installing Python, Node.js,
  Rust or a package manager. Windows now includes the C runtime in its executable.
- Install from crates.io with Cargo. Windows source packaging now normalizes
  manifest line endings; staged packages include the resources needed to build.
- Use platform-specific Codex/Claude Marketplace Plugins with a bundled native
  executable. Lite MCP starts without npm, a shell bridge or a first-run binary
  download. Select the archive for your Host, operating system and architecture.
- Preserve multiple sources for one research claim, stable cross-stage identities
  and source navigation in Research Graph. Host-assisted review still precedes
  normalization; missing evidence does not become a verified graph relationship.
- Consolidate completed stages into detailed versioned documents with source
  coverage and accumulating history. Humanizer polishes the final prose before
  preview/save while preserving facts, citations, numbers and uncertainty.
- Keep retention review advisory and file-specific. The user alone chooses and
  removes files; the assistant cannot delete, move or truncate the originals.

## Install

For immediate use, choose the platform archive under **Assets**, verify it against
`SHA256SUMS`, and extract it into a new directory. Run `./qiongli --help` on
macOS/Linux or `.\qiongli.exe --help` in Windows PowerShell. Skills, templates and
MCP resources are embedded; PATH setup is optional. GitHub's **Source code**
downloads require compilation and are separate from these executable archives.

Alternatively:

```sh
cargo install qiongli --version 2.0.0-beta.1 --locked
npm install --global qiongli@2.0.0-beta.1
python -m pip install --pre qiongli==2.0.0b1
```

Choose one installation route. Cargo builds from source and needs Rust 1.97+
and a native linker; npm needs Node 18+, and PyPI needs Python 3.9+. These package
managers expose `qiongli` and `ql`. npm uses `next`; `latest` remains on 1.x.
Cargo prereleases use the exact version, with no `next` channel.

For MCP, configure your Host with the executable's absolute path and
`mcp serve --profile full --transport stdio`, or choose `--profile lite`.
Full exposes 32 tools; Lite exposes 14. Models, accounts and online services
remain separately configured. Downloading the CLI does not register a Host.

The six Plugin archives and `marketplace-plugins.json` identify the supported
Host/platform combinations and their immutable distribution refs. Existing
generic alpha.8 Plugins retain their historical npm bridge until users select
the new platform entry. No automatic OS selection is implied.

## Limits and rollback

This beta retains preview, approval and revision checks for research writes.
It does not claim complete 1.x replacement, App delivery, managed activation,
signed self-update, notarization, automatic migration or universal graph extraction.
Intel macOS, Linux ARM and Windows ARM-native are not advertised binary targets.

Upgrade into a new directory or use your chosen package manager. Keep research
data and the previous executable. Roll back by selecting the previous version;
changing binaries does not reverse data migrations. Published tags, crate
versions and release assets are immutable.
