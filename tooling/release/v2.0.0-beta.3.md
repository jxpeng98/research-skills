# Qiongli v2.0.0-beta.3

Beta.3 makes everyday commands easier to find and terminal output easier to read.
GitHub downloads, npm, PyPI and Cargo share the same native CLI.

## Commands and output

- Run `qiongli` for a compact command guide. Use `qiongli help project create`
  for one operation, or `qiongli help all` for the complete reference.
- Use `qiongli project`, `qiongli config`, `qiongli content` and `qiongli install`
  for their usual read-only queries. `qiongli project show <id>` reads one project.
- Run `qiongli setup` to review installed CLI versions. In beta.2, running without
  arguments opened this review; beta.3 shows help instead. The review still leaves
  archive, uninstall and PATH changes to you.
- Terminal queries now show readable summaries. Redirected output retains its
  previous format. Choose `--json` for structured output or `--text` for a readable
  report, placing one output flag before the command or at the end.
- Full MCP now accepts `qiongli mcp serve --profile full`; stdio is the default.
  The profile remains explicit, and MCP output stays protocol-only.

Existing command forms remain available. `ql` and `qiongli` accept the same
commands in package-manager installs. Project writes retain their preview,
approval and revision checks, and text previews preserve the complete plan values.

## Install

For direct use, download the complete archive for macOS ARM64, Windows x64 or
Linux x64 from **Assets**, verify `SHA256SUMS`, extract, and run `./qiongli`
(Windows: `.\qiongli.exe`). No separately installed Python, Node.js, Rust or
package manager is needed. Linux requires glibc 2.35+.

Alternatively, choose one package manager:

```sh
npm install -g qiongli@2.0.0-beta.3 --allow-scripts=qiongli --foreground-scripts
python -m pip install qiongli==2.0.0b3
cargo install qiongli --version 2.0.0-beta.3 --locked
```

npm needs Node 18+, PyPI needs Python 3.9+, and Cargo builds from source with
Rust 1.97+ and a native linker. npm's `next` tag follows prereleases.

The npm command above allows Qiongli's installation review for this invocation
and connects it to the terminal. Headless installs skip the review; disabling
install scripts still leaves a working CLI. After pip or Cargo installation,
run `qiongli setup`. If an older executable appears first on PATH, use the new
executable's full path.

## Publication and limits

Release Automation qualifies the exact tag on all three platforms before
publishing GitHub assets, then dispatches the npm, PyPI and Cargo workflows.
Each registry becomes available when its own checks and upload complete.
Platform Plugin archives are included; external Marketplace catalog updates
remain separate.

This release does not automatically remove or archive installations, change
models or Host settings, or migrate research data. To roll back, use a retained
executable or reinstall a pinned version through its original package manager.
Switching binaries does not reverse data migrations. Published tags and assets
remain immutable.
