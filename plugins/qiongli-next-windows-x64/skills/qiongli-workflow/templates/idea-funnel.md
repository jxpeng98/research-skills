# Academic Idea Funnel

Save to: `RESEARCH/[topic]/context/idea_funnel.md`

Use this artifact before Stage A work when the project starts from a vague topic, a brainstorm, or several possible research directions. The goal is to select a defensible paper idea before drafting research questions, contribution statements, venue analysis, or gap scans. This artifact does not replace `context/boundary_review.md`; it hands off the selected idea and unresolved scholarly risks to the boundary review.
