# Stage L - Coursework And Learning Assessment

Stage L supports assignment brief intake, rubric mapping, coursework planning, drafting, revision, and final readiness checks.

Use Stage L when the user brings coursework, a module assignment, a marking rubric, learning outcomes, a reflective assessment, a case analysis, a portfolio task, or a capstone coursework brief.

Required boundaries:

- Do not promise marks or grades.
- Do not invent assignment rules, sources, data, personal experience, or institutional AI policy.
- Keep missing rubric, learning outcome, source, and user-material gaps visible.
- Keep coursework workflow classification separate from subject routing.

Primary artifacts:

- `assignment/brief.md`
- `assignment/rubric_map.md`
- `assignment/learning_outcomes.md`
- `assignment/academic_integrity_notes.md`
- `coursework/outline.md`
- `coursework/claim_evidence_plan.md`
- `coursework/draft.md`
- `coursework/revision_plan.md`
- `assignment/submission_checklist.md`
